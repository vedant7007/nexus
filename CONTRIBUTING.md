# Contributing to NEXUS

Thanks for taking the time to help.

## Before you start

- For anything larger than a small fix, open an issue first so we can agree on the approach.
- Be kind. This project follows the [Code of Conduct](CODE_OF_CONDUCT.md).

## Making a change

1. Fork the repo and create a branch from `main`.
2. Install dependencies with `npm ci` and run the app with `npm run dev`.
3. Keep the change focused and add or update tests for any behaviour you change.
4. Before opening a pull request, make sure `npm run lint` and `npm test` pass.
5. Describe what changed and why in the pull request.

## Reporting bugs

Open an issue with steps to reproduce, what you expected, and what happened instead.
Security issues go through [SECURITY.md](SECURITY.md), not public issues.
